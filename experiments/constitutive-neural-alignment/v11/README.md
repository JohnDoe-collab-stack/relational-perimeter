# Complete-property scaling campaign v11

This campaign supersedes none of the historical evidence. The v5 observation,
the v7 resource-budget failure and the complete v8 result remain immutable and
their hashes are checked by the v11 protocol.

Unlike v8, v11 does not measure a contract whose semantic obligations are
`Unit`. The generated artifact family grows its executed neural network,
heterogeneous causal graph and structural certificate. Every generated neuron
is on the executed dependency chain consumed by the declared output; the final
neuron reads both the received input and the preceding chain value, and its
threshold makes that chain value operationally relevant. Every complete check
also constructs and forces seven distinct obligations: requirement encoding,
an executed causal role, action, incorporated authorization, effect, a finite
future whose trace grows at every step, and the exact native run history.

## Freeze and run order

1. Commit the implementation and verify that the worktree is clean.
2. Run `python scripts/freeze-complete-property-scaling-v11.py`.
3. Commit the frozen protocol without changing the frozen source files.
4. Run the exact `confirmatory_command` in `scaling-protocol.json` once.
5. Run `python scripts/check-complete-property-scaling-v11.py --require-results`.

The runner refuses a dirty tree, an unavailable source commit, changed sources,
or an existing result file. Until step 2, the protocol intentionally has status
`draft-awaiting-stable-source-commit`; this is not confirmatory evidence.

## Interpretation boundary

The canonical certificate and delta byte counts use the binary-size model fixed
in Lean. Peak RSS is measured separately at process level. Incremental and
full-reference phase units are published separately; initialization is counted
once per trace. These are deterministic accounting quantities. Neither phase units nor transported
fragment counts are elapsed-time gains. Only the preregistered cumulative-time
criterion decides the practical P8/S6 economy. A negative decision is published
unchanged and does not weaken the formal checker theorems.
