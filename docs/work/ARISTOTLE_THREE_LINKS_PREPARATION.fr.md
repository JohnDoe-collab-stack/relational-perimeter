avec examen obligatoire des trois raccords : références de chaque nœud, pont

Le commit scientifique contient 312 fichiers suivis. La validation locale
propre a passé les builds public/complet, les deux verifiers Windows sur 181
fichiers Lean, 26 fixtures, le sweep de 18 333 constantes sans dépendance
axiomatique manuscrite et la campagne ciblée de cinq variantes. Une seconde
passe de 12 commandes a rejoué builds, verifiers, clients nouveaux et anciens,
sans changement des sources. Les 299 fichiers protégés sont byte-identiques.
Ce sont des vérifications d’auteur, pas un nouvel audit indépendant.

Les sources, le bundle Git complet, les pins, empreintes et runtimes officiels
seront fournis hors ligne afin que l’audit ne dépende pas du réseau GitHub.

le prompt transmis et les pièces jointes. Une étape d’accueil technique peut
précéder l’instruction scientifique afin de livrer les fichiers volumineux ;
